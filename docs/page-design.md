# AI竞品情报雷达 - 产品首页设计文档

## 1. 页面定位

页面名称：

Home（产品首页）

页面类型：

Landing Page

访问权限：

无需登录

## 2. 页面目标

首页用于向用户展示 AI 竞品情报雷达的核心价值。

用户进入页面后，需要快速理解：

- 产品是什么
- 可以解决什么问题
- 如何帮助用户分析竞品

设计目标：

- 简洁
- 专业
- 高级 SaaS 产品感
- 突出 AI 属性
- 避免传统后台系统风格

设计策略：

- PC First
- 响应式布局
- 后续支持平板和移动端适配

## 7. 核心功能展示

采用三栏卡片布局。

### 功能一：自动监控

说明：

持续追踪竞品官网、更新日志等公开信息。

能力：

- 页面变化检测
- 信息采集
- 历史记录

---

### 功能二：AI分析

说明：

利用大语言模型理解变化内容。

能力：

- 内容总结
- 变化原因分析
- 影响评估

---

### 功能三：趋势洞察

说明：

通过数据分析发现市场趋势。

能力：

- 趋势分析
- 竞品对比
- 风险提醒

## 10. Footer

展示品牌信息、导航链接和版权声明。

### 布局

纵向三行居中布局：

```
┌─────────────────────────────────────┐
│          AI 竞品雷达                  │  ← 品牌区（居中）
│       让AI成为你的市场情报助手          │
│                                      │
│  产品       关于        法律           │  ← 三列导航链接（居中）
│  功能介绍   团队博客    隐私政策        │
│  工作流程   联系我们    服务条款        │
│  产品预览              GitHub         │
│                                      │
│  © 2026 AI Competitor Radar.         │  ← 版权信息（居中）
│  All rights reserved.                 │
└─────────────────────────────────────┘
```

### 内容

**品牌区**：

- 主标题：AI 竞品雷达
- 副标题：让AI成为你的市场情报助手

**导航链接**（三列）：

- 产品：功能介绍、工作流程、产品预览（锚点跳转：`#features`、`#workflow`、`#preview`）
- 关于：团队博客、联系我们（暂时占位 `#`）
- 法律：隐私政策、服务条款、GitHub（外链至项目仓库）

**版权行**：

- © 2026 AI Competitor Radar. All rights reserved.

### 样式

- 背景：`var(--el-bg-color-page)`（浅灰底，与页面主体区分）
- 内边距：`4vh 5vw 2vh`
- 品牌标题字号 `1.5vmax`、加粗；副标题 `1.2vmax`
- 链接标题字号 `1.2vmax`、加粗；链接文字 `1vmax`
- 链接 hover 时颜色变深（`--el-text-color-primary`）
- 版权文字 `1vmax`、颜色 `--el-text-color-placeholder`

### 组件

对应组件：`LandingFooter.vue`
