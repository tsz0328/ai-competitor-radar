# AI竞品情报雷达 - 登录页设计文档

## 1. 页面定位

页面名称：

Login（登录页）

页面类型：

独立路由页面（`/login`）

访问权限：

需登录（本身为登录入口；首页「登录 / 开始使用」跳转至此）

---

## 2. 设计目标

- 延续首页的「AI / 雷达」视觉基因，强化产品记忆点。
- 登录/注册表单在专业感与轻量感之间平衡，不做传统后台登录的沉重感。

---

## 3. 整体布局

左右分栏（PC First）：

```
┌──────────────────────────┬──────────────────────────┐
│  左侧：品牌面板 BrandPanel │  右侧：表单面板 FormPanel   │
│  （雷达扫描动画 + 标语）    │  （登录/注册 + 第三方登录）  │
└──────────────────────────┴──────────────────────────┘
```

- 页面背景：蓝→白蓝渐变（`135deg` 线性渐变），呼应首页主色。
- 右侧表单面板：圆角卡片（`2vmax`），蓝色半透明描边 + 柔和阴影，悬浮于渐变背景之上。

## 4. 左侧品牌面板（雷达动画）

核心视觉元素：Canvas 雷达扫描动画（`RadarCanvas.vue`）。

设计要点（与实现保持一致）：

- **同心圆网格（5 圈）+ 十字线**：构成雷达底纹。
- **扫掠点亮**：一条扫线沿圆周旋转，扫过的网格段由暗变亮、扫过后渐隐——表现「扫描」语义。
- **颜色插值（紫→白）**：网格颜色按强度在「品牌紫 `(160,120,250)`」与「纯白 `(255,255,255)`」间线性插值；被扫到时偏紫、未扫到时纯白。
- **径向透明度衰减（圈内→圈外渐变）**：每圈有独立基线透明度 `baseAlpha = 0.25 + 0.75*(r/radius)`（内圈更暗、外圈更亮），叠加扫掠提亮，形成从圆心到边缘的径向渐变；十字线同样沿「圆心→边缘」做线性透明度渐变（`0.25 → 1`）。
- **发光 + 加粗**：扫线前沿附近（强度 > 0.7）的网格段叠加紫色辉光（`shadowBlur`）并脉冲加粗（`lineWidth 1px → 3.5px`），与扫线融为一体。
- **头部平滑**：扫线头部穿过某网格段时，在头部角度处将该段切成「已扫（紫渐变+发光）」与「待扫（纯白 1px）」两段，避免段间硬切换造成的色差断层 / 闪烁。

#### 光点（Blip）发光

- **仅被扫到才亮**：每个光点平时隐藏，仅当扫线进入其 `BLIP_FADE`（0.5π，约 90°）窗口内时随角度差渐隐亮起，扫过即消失（非常亮）。
- **单色发光体**：被扫到时用 `globalCompositeOperation = 'lighter'`（加法混合）让光点在深色背景上变亮，绘制**一个**径向渐变圆（半径 `blipR = r0 + r0*0.7*boost`，`r0 = max(2.5, radius*0.02)`）——圆心 `boost` 满色 → 边缘透明，一种颜色、从内向外平滑淡化、无白色掺入；叠加 `shadowBlur`（`28+22*boost` px）外扩辉光提升亮度，无多段停止点故不形成可见圈。绘制结束复位混合模式与 `shadowBlur`。
- **脉冲感**：`boost` 由角度差驱动（刚扫到时为 1），半径与辉光同步放大，扫线离开时平滑渐隐。

## 5. 右侧表单面板

元素（自上而下）：

- 顶部：「< 返回首页」链接（返回 Landing）。
- 品牌行：雷达图标 + 「AI 竞品雷达」渐变文字（紫→深蓝）。
- 标题「欢迎使用」+ 副标题「登录以继续你的市场情报分析之旅」。
- Tab 切换：登录 / 注册（底部一条随选中项平移的指示器）。
- 登录表单：用户名或邮箱、密码（可显/隐）、记住我 + 忘记密码？、登录按钮（蓝紫渐变胶囊）。
- 注册表单：用户名、邮箱、密码、确认密码、注册按钮。
- 分隔线「其他登录方式」+ 第三方登录：GitHub / 微信 / 邮箱登录。
- 底部：「还没有账号？立即注册」切换链接。

> 注：当前表单为静态展示（提交逻辑预留 `onLogin / onRegister / onOAuth` 接口，登录提交接入 JWT 见里程碑 4）。
